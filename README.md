# SelfFit

웹캠 기반 모의 면접 자가진단 서비스. 면접 중 **시선·표정·집중 상태**를 AI가 실시간으로 분석해 토스트로 알려 주고, 종료 후 행동 리포트를 제공합니다.

## 배포
- 프론트: https://self-fit-ashy.vercel.app
- 백엔드: https://self-fit.onrender.com
- 추론 서버(AI 분석): **배포하지 않음** — GPU 리소스 비용 문제로 로컬 실행만 지원

배포본에서는 로그인, 세션 생성, 웹캠 프레임 전송, 녹화 업로드, 리포트 화면까지 정상 동작합니다. 다만 추론 서버가 없어 실제 시선·표정 분석 수치는 나오지 않고, 규칙 기반 폴백(질문 목록, 목업 알림 등)으로 동작합니다.

## 주요 기능
- **직군별 맞춤 질문** — 면접 시작 전 직군(백엔드/프론트엔드/AI/디자인 등)을 선택하면 그에 맞는 질문 세트로 진행 (`/interview/setup`)
- **실시간 웹캠 분석** — 시선 이탈·긴장 표정·집중 저하 감지 시 토스트 알림 (사용자가 켜고 끌 수 있음)
- **영상 업로드 분석** — 녹화본 업로드만으로도 프레임 분석 + STT(음성 인식) + LLM 요약을 거쳐 동일한 리포트 생성 (`/upload`)
- **행동 리포트** — 답변별 지표와 LLM 기반 총평 제공
- **마이페이지** — 지난 세션 기록과 시선·집중 추이 차트 (`/mypage`)
- **다크 모드** — 전역 테마 토글 지원

## 사용자 흐름
```
로그인 → 직군 선택 → 질문 목록 확인 → 면접 시작(웹캠) → 질문별 답변 → 종료 → 리포트
                                             │
                                    시선 이탈·긴장 표정·집중 저하 시 토스트 알림 (켜고 끌 수 있음)

(또는) 로그인 → 영상 업로드 → 분석(프레임 + STT + LLM) → 리포트
```
